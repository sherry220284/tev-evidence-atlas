# Limitations

- 来源是有界整理，不是穷尽TEV工程历史的系统综述。未取得或未核实的SI细节不填入协议。两篇2026文献当前用于方法和定位比较，没有并入168条历史测量。
- 历史测量缺少统一底物、温度、构建、酶量、重复数与不确定性定义；168行不等于168次独立实验。没有可以直接混训的同尺度标签。
- Cabrita正文/表格、Sanchez图注/Methods及补充标签等冲突继续保留。源内歧义不因数据库能运行而消失。
- 35条精确成熟域是偏倚选择集，不是1505条全面分析；27/35为Potyvirus。无根短蛋白基因树不是物种树，重组未评估，长支复核不能证明排除了全部异常。
- 保守性/属平衡只描述该集合；没有天然同源4℃催化标签。宿主、地理和天然环境不构成冷适应证据。
- 专利相对端点、广泛权利要求、NEB商品声明是三种证据，产品身份未知。不同商业U、质量和摩尔量不可无依据换算。
- 论文原图、PDF、字体和未公开商业序列未纳入Git。旧来源路径仅作溯源；从原文自动重抽取并非本版离线复现范围。
- 五轮主动学习、ESM2/GP/树模型与共进化特征只是设计框架。现有路线受局部搜索限制是研究假设，未证明局部最优；没有新序列、模型训练、实验增益或新冷适应机制结论。
- 无Microsoft PowerPoint客户端环境；仅能报告实际LibreOffice/PDF与OOXML检查，不能声称已在全部桌面平台验收。
