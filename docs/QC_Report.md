冻结数据包含36个来源限定工程变体、44个构建、115条突变记录、168条测量、26条协议、326条证据链接、69条审计。18条sources包括结构、序列和厂商规格，不等于18篇实验论文。P8118有1条单列厂商记录，不进入168条测量，不映射任何专利SEQ ID。

本轮Nam更正涉及7处冗余字段，根源是一类归属错误：标准液的DTT不能推定为反应液条件。逐处保留旧值、修订值、原文定位和独立审计；不把7处字段说成7类错误。原始文献中未报告的温度、浓度、体积、重复等仍为NULL或“未报告”。

实际验证运行时是Python 3.6.8、NumPy 1.19.5、Matplotlib 3.3.4、Biopython 1.79、Pillow 8.4.0。精确依赖另见 `requirements-tested.txt` 和 `data/provenance/tested_environment.json`。推荐的Python 3.10/3.12配置及GitHub Actions已提供，但当前尚未在这些解释器或GitHub托管环境执行，不能据此声称跨版本CI已通过。

本轮PPT使用python-pptx与LibreOffice 24.8生成/渲染；没有在Microsoft PowerPoint桌面程序实际打开检查。中文字体名与PDF字体清单见私有交付的 `presentation/Presentation_QC.json`；字体文件不随包分发。

仍需明确的边界：论文抽取尚需按原文人工独立复核；第三方PDF/原图不进入Git源包；MAFFT/IQ-TREE重新推断需安装记录版本并执行Methods中的命令；本次离线复核读取归档树。历史争议、天然序列冷活性UNKNOWN、模型标签缺失均保留。当前没有训练模型，没有生成新突变序列，没有做4℃新实验，没有推送或公开发布。
