# Five-round Active Learning plan — proposed, not executed

主要方法参考Yang et al., Nature Communications 16:714 (2025)，DOI [10.1038/s41467-025-55987-8](https://doi.org/10.1038/s41467-025-55987-8)，主文Methods/Table1/Figs4–5与SI。ALDE的序贯实验回流、模型比较和不确定性评估可借鉴；其任务结果、模型排序和候选预算不保证迁移到TEV。原Fig4的96+4×96设计是原研究场景，不能替代本项目预算。

## 表征与代理模型

| 特征 | 小样本用途 | 风险与比较基线 |
|---|---|---|
| 对齐位点one-hot | 透明、低成本，固定坐标下的首选基线 | 跨天然骨架插缺需单独映射；严格防止相近序列跨折泄漏 |
| ESM2冻结嵌入 | 序列背景与较远同源关系 | 不在小样本直接大规模微调；按训练折拟合降维/标准化，检查是否优于one-hot |
| 实验结构/保守性 | 位点环境和生物约束 | 结构证据等级分列，预测结构不能冒充实验结构；特征不能被当作机制证明 |
| 共进化/天然配对 | 蛋白酶—底物兼容描述 | 来源引用ProSSpeC；配对保留，样本有效数/同源偏倚需估计，不把3817当独立低温标签 |

GP（适合one-hot/低维嵌入，显式噪声项）与树集成（随机森林/extra trees/boosting ensemble）同时作为基线。比较固定候选池上的held-out误差、排序、校准和实际回流表现，不预设GP必胜。深度模型只在数据量和外推证据充分时加入。

## 采集、验证与目标

Greedy按预测均值选择，易集中；UCB=μ+βσ提供可调探索；Thompson Sampling按后验函数样本选择。树集成分歧不自动等于校准后验；先检验覆盖率及残差/不确定性关系，再用于采集。批次中保留序列多样性与少量随机探索，避免近邻重复。β和各配额只用已完成轮的验证/模拟决定，不能用未来测试标签调参。

按骨架、谱系/序列相似簇和实验批次分组验证；同一构建重复和近邻不能跨训练/验证。归一化、特征选择、降维和校准仅在训练折拟合。保留前瞻轮次验证；bootstrap/集成报告区间与经验覆盖（例如80%/95%），检查批次漂移与异方差。小样本覆盖率本身误差较大，应报告不确定性。

主目标为4℃固定[S]比初速，应用目标为融合底物同时间/剂量下切割；表达/可溶产量、特异性和稳定性为辅助目标/硬门槛。用Pareto或有约束采集，导师先确定最低应用门槛；不把各论文效率当同量纲训练标签。失败表达、低于检测限和区间值保留，按明确删失模型或失败类别处理，不填0后混合回归。

## 预算与逐轮Go/No-Go（所有阈值拟议）

总计80+96+96+96+80=448个不同候选。共同对照、重复孔、重测及独立纯化批次另计实验孔/反应数，因此448不是全部实验工作量。相同序列重复测量不重复计候选。

| 轮次 | 新候选上限 | 工作与门槛 |
|---|---:|---|
| R1 | 80 | 方法先行：共同对照稳定，空白可分，4℃实测温控，浓度/时间线性；初速转化≤10%、技术CV建议≤20%。不通过先修实验，不开始选优迭代 |
| R2 | 96 | one-hot/GP及树基线；按骨架/批次分组。至少一个模型在组外排序/误差优于均值或随机基线，否则保持多样性/随机探索，不声称AL有效 |
| R3 | 96 | 检查不确定性覆盖与误差关联；盲测新批次，重复确认前轮较好结果。若漂移或校准失败，先校正批次/噪声，减少依赖σ的采集 |
| R4 | 96 | 与Greedy/多样性基线比较；应用融合底物加入Pareto，独立批次复测。若短肽提高但应用无改善，调整任务/目标而非仅追高短肽 |
| R5 | 80 | 预留前瞻确认、商业剂量与时间曲线、产量及非特异切割；未超过预设共同基准则报告阴性/边界，停止无证据扩增 |

每轮登记：稳定ID、序列来源/坐标、表达批次、酶量和底物批次、原始曲线/胶图、温控、空白、重复、拟合与QC状态。冻结当轮数据版本及划分/模型配置/随机种子（拟议20261029，实际执行再登记），输出下一轮选择理由与风险。这里没有候选序列文件、拟合模型或已获增益。
